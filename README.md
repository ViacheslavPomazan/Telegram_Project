# Telegram_Project

Це проєкт для визначення ступенів загроз під час повітряних тревог, які у Сумах лунають на протязі всієї доби. 
Голона мета проєкту - класифікувати загрози і давати звуковий сигнал під час тієї, яку яку ти вважаєш для себе самою небезпечною (наприклад КАБи). А то якщо реагувати на всі тривоги, особливо вночі, то не буде часу ні поспати, ні для роботи, ні для відпочинку.
Паралельно проєкт вирішує учбові цілі, такі як:
  * Збереження інформації в базі даних MySQL для подальшого аналізу.
  * Збереження даних в JSON файлі.
