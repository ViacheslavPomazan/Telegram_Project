# Telegram_Project

Це проєкт для визначення ступенів загроз під час повітряних тревог, які у Сумах лунають на протязі всієї доби. 
Головна мета проєкту - класифікувати загрози і давати звуковий сигнал під час тієї, яку яку ти вважаєш для себе самою небезпечною (наприклад КАБи). А то якщо реагувати на всі тривоги, особливо вночі, то не буде часу ні поспати, ні для роботи, ні для відпочинку.
Паралельно проєкт вирішує учбові цілі, такі як:
  * Збереження інформації в базі даних MySQL для подальшого аналізу.
  * Збереження даних в JSON файлі.

Схема в mysql складається з 4-х таблиць - таблиця фактів `alerts` і 3 таблиці категорій:
 * `tampletes` зберігає шаблони тексту, що частозустрічаються у повідомленнях;
 * `danger_dagrees` - назви ступенів небезпеки:
 * `channels` - назви telegram каналів, з яких береться інформація.
